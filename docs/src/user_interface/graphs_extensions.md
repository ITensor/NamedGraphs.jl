# Graphs interface extensions

```@meta
CurrentModule = NamedGraphs.GraphsExtensions
CollapsedDocStrings = true
```

The `NamedGraphs.GraphsExtensions` module provides generic extensions of the
Graphs.jl interface that work on any `Graphs.AbstractGraph`, not just named
graphs. This section documents the most commonly used functions and will grow
over time.

```@docs; canonical=false
GraphsExtensions
subgraph
incident_edges
```
